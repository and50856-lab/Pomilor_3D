# Pomilor 3D (бета 0.1)

Песочница в стиле GTA для Android. Движок: **Godot 4.7.2**, рендер Mobile (Vulkan, с откатом на OpenGL).
Вся графика пока процедурная (кубы, цилиндры, шейдеры) — модели и текстуры из Blender подключаются позже, см. ниже.

## Как собрать APK

1. Создай пустой репозиторий на GitHub и залей в него всё содержимое этого архива (папка `.github` обязательна).
2. Открой вкладку **Actions** → **Build Android APK** → при необходимости **Run workflow**.
3. Через ~10–15 минут в запуске появятся артефакты: `Pomilor3D-debug-apk` (APK для установки) и `logs`.

Если запуск красный — скачай артефакт `logs` (там `selftest.log` и `export.log`) и пришли текст ошибки.
Перед сборкой workflow сам запускает игру без экрана (самотест): строит город, стреляет из всего оружия,
садится в машину, угоняет её у водителя. Ошибки скриптов попадают в `selftest.log`.

## Управление (телефон)

- Левая часть экрана: коснись в любом месте — появится джойстик под пальцем.
- Правая часть экрана (вне кнопок): повернуть камеру.
- Кнопки справа: ОГОНЬ, ПРЫЖОК, БЕГ (переключатель), ПЕРЕЗ., БРОСИТЬ, ДЕЙСТВИЕ (сесть/угнать/подобрать).
- Вверху справа: круговое меню оружия, ВЕЩИ (оружие, машины, настройки), пауза, ВИД (1-е/3-е лицо).
- В машине: слева ◄ ►, справа ГАЗ / НАЗАД / СТОП (ручник) / СИГНАЛ, ВЫЙТИ. Камеру вращает палец по экрану.

ПК (для проверки): WASD, Shift, Space, ЛКМ — огонь, ПКМ+мышь — камера, E, R, V, G, H, Tab, Esc.

## Куда класть свои ресурсы (из Blender)

Если файл существует — игра берёт его, иначе рисует процедурную версию:

| Что | Путь | Требования |
|---|---|---|
| Машина | `assets/vehicles/<id>.glb` (`g_class`, `vaz`, `gallardo`) | 1 ед. = 1 м, перед = −Z, начало координат на высоте оси колёс. Узлы: `Wheel_FL`, `Wheel_FR`, `Wheel_RL`, `Wheel_RR`, `Door_L` (петля двери), `Seat` |
| Оружие | `assets/weapons/<id>.glb` (`bat`, `deagle`, `ak47`, `mossberg`, `rpg`) | перед = −Z, начало в рукоятке, узел `Muzzle` у дула |
| Иконка | `assets/icons/<id>.png` | прозрачный фон, квадрат |

Размеры и параметры машин — `vehicle_defs.gd`, оружия — `weapon_defs.gd`.

## Структура (все файлы лежат в корне репозитория)

- `game_world.gd` — сборка города и игры по шагам (экран загрузки)
- `settings.gd` — графика, тени, дальность, сглаживание, анизотропия, bloom, лимит FPS
- `player.gd`, `npc.gd`, `vehicle.gd`, `ai_driver.gd` — игрок, пешеходы, машины, трафик
- `hud.gd` — сенсорный интерфейс и круговое меню
- `lint_gd.py`, `selftest.gd` — проверки перед сборкой
